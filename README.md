# <span style="color:red;"> Que es NEXO? </span> 
## NEXO se presenta como una solución integral tecnológica y pedagógica diseñada específicamente para el Centro Universitario de Guadalajara (CUGDL). Su objetivo principal es mitigar  la deserción temprana y la disolución de equipos de trabajo, mediante una pagina tipo GitHub que funciona como incubadora de proyectos, para facilitar el trabajo colaborativo con herramientas de trabajo y  recursos para aprender.
